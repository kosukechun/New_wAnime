- 海外ドラマ枠を追加して再取得。新規40作品、既存作品の重複追加0、取得エラー0。

- 出演者：声優718、俳優・女優431、合計1,149人。
- 日本の番組表：396件。国外の放送・世界配信予定とは別地域で保存。
- Wikidataの本人外部IDを照合し、日本語Wikipediaリンク294件を確認。
- 日本語「花澤香菜」からTVmazeのKana Hanazawa（外部ID49935）を外部検索で取得。保存済みの日本語名・出演作品・日本語Wikipediaリンクも確認。

- PostgreSQLを停止・再起動し、200作品と出演者情報が保持されることを確認。

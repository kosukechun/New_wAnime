# データの出典・利用条件

New_wAnime自身のコードと外部コンテンツの権利は別です。ポスター／人物画像／外部サービスのロゴは取得元・権利者に帰属します。画像をオリジナル制作物として扱いません。

| 取得元                                                                                       | 実装と帰属                                                                                                            |
| -------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| [TVmaze API](https://www.tvmaze.com/api)                                                     | 公開API。TVmazeをリンク付きで帰属表示。データはCC BY-SA、加工データも同条件。画像CDNへの直接リンクは公式API文書に記載 |
| [TMDB FAQ](https://developer.themoviedb.org/docs/faq)                                        | 非営利用途を想定。公式ロゴと指定クレジットを画面の情報源ページへ表示。商用利用は提供元へライセンス確認                |
| [TMDB Watch Providers](https://developer.themoviedb.org/reference/tv-series-watch-providers) | JPの料金区分別データ。JustWatchのクレジットを表示。返却されない直接リンク、開始日、独占は推測しない                   |
| [MAL公式API](https://myanimelist.net/apiconfig/references/api/v2)                            | Client IDを設定して公式エンドポイントだけ利用。大量の全件収集をせず、直近クールと今後約12か月の公開済み作品へ限定     |
| [AniList利用規約](https://docs.anilist.co/guide/terms-of-use)                                | 一覧／視聴管理サービス等の利用制限を考慮し無効。許諾取得を前提に有効化。許諾確認用フラグは法的許諾を代替しない        |
| [Wikidata](https://www.wikidata.org/wiki/Wikidata:Data_access)                               | CC0の構造化データ。本人の外部ID一致を使用。候補複数の場合は紐付けない                                                 |
| Wikipedia                                                                                    | 本文はCC BY-SAとして元記事へリンク。日本語記事はWikidataのjawiki sitelinkから取得。名前から記事URLを決め打ちしない    |

取得時のURLと確認日時を作品・配信・番組表に保存します。公式サイトはリンク表示と管理者が照合したデータの入力のみで、自動スクレイピングしません。新しい取得元を追加するときは、その時点の利用条件・robots.txt・API制限を確認してください。

TMDBのロゴは公式配布ファイル `https://www.themoviedb.org/assets/2/v4/logos/v2/blue_square_2-d537fb228cf3ded904ef09b136fe3fec72548ebc1fea3fbbd1ad9e36364db38b.svg` を変更せず同梱しています。

一般公開時には利用範囲・商用性・コンテンツの再利用条件を運営者が確認し、必要な許諾を取得してください。
